# 独立资金锁实验 Flow Locks V0.1

这是新的独立目录与实验分支，不更改 a-share-alpha-lab 的 main。仅供研究，不自动执行买卖。

## 能做的事情
- 针对 000100、600206、603993，从东方财富公开行情页面接口读取日级和盘中分钟资金流，以及日K线价格/成交额。
- 对三个已经结束的交易日计算：主力资金强度 = 主力净额之和 ÷ 成交额之和 ×100%。
- 检查最新分钟资金是否过期，计算 MA5/MA10/MA20 和日内主力资金估算比例。
- 资金数据无效、时间戳过期、日期不齐时拒绝给出研究开仓信号。

## 一键运行（Python 3.10+，标准库）
python -m unittest discover -s flow_locks/tests -v
python -m flow_locks.cli --symbols 000100 600206 603993
python -m flow_locks.cli --symbols 000100 --json-out flow-snapshot.json

## 数据与阈值限制
- 东方财富 f52 是数据供应商推算的主力订单资金净额，不是机构账户真实净买入。
- 3% 是本实验对主力净额/成交额的待验证阈值，既不是指南针多空资金1%，也不是之前跨平台估算的主力+游资5.47%。
- 缺少可验证的同一时间段20日成交量基准，因此活跃锁一直显示未知，buy_signal 始终为 false。
- 日级资金流和K线字段可能不同步或被源站修改。必须在GitHub实际运行之后才能确认接口是否可用。
- GitHub Actions 定时任务最快通常为5分钟，可能延迟，只在默认分支触发；本实验分支不启用定时采集。
- 公共接口没有稳定可用性保证，使用前应核对授权和数据提供方使用条款；不向GitHub保存个人持仓、交易账户或密钥。
